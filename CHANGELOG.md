# Changelog

## 2.0.1

- Исправлен баг: Chunky шлёт `GenerationCompleteEvent` при любом завершении цикла генерации (в том числе при паузе, `/chunkyqueue stop`, рестарте сервера), а не только при настоящих 100%. Плагин слепо доверял этому событию и терял место прогрузки:
  - `/chunkyqueue resume` после `stop` не возобновлял генерацию;
  - пауза по игроку онлайн не возобновлялась при опустении сервера;
  - рестарт сервера посреди прогрузки не подхватывал её заново.
  Теперь плагин различает реальное завершение от паузы/остановки по флагу `cancelled` в `Chunky/tasks/<world>.properties`, который сам Chunky синхронно пишет перед событием — это не подвержено гонке потоков между `GenerationProgressEvent` и `GenerationCompleteEvent` на быстрых/маленьких генерациях.
- `config.yml` теперь встроен в jar, поэтому `saveDefaultConfig()` реально создаёт конфиг по умолчанию при первом запуске, а не оставляет пустую очередь без объяснений.
